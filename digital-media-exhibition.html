Description

When mentor Dr. Ben Bryne approached me to work on this website back in 2024, I had no idea that this moment would solidify me as the website guy. In fact I was actually pretty reluctant to take on this project because of the amount of labour I knew that was about to fall upon me.

This would mark the first time I'd embark on a project that pushed me to my limits, while at this time tools such as Claude or ChatGPT weren't as heavily used in workflows due to it's primitive state. In which programmer and fellow digital media practioner Ava Vu became a key collaborator in this project taking on mobile optimisation work and general typescript and programming assistance.

My key role in this project became the website designer and assistant developer. What was produced is a container housing 100+ students, which was extremely labourous at the time. If I had the tools today, the website's stylistic direction would feel a lot more polished.
