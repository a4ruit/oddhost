Luminous Festival

2025 — Interactive Installation

Live festival installation built for an outdoor forest environment, featuring dual vertical displays driven by real-time MediaPipe hand tracking via a Python UDP sidecar. Two-hand distance controls a boid flock as a force field — adjusting frequency, speed, count, and scale of ASCII bird silhouettes in real time. Layered with HDRP custom post-process GLSL shaders, an ASCII whale predator that hunts the flock, and world-space data visualisation HUDs that follow hand position.

Unity HDRP MediaPipe Python UDP GLSL Shaders Boids Live Performance
