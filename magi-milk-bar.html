Description

This was the first project produced from MAGI, and the first attempty I had synthesised a project using two softwares that had not normally been combined at this time. Which was the combination of TouchDesigner and Blender. Using blender as a real-time renderer at this time was not usual practice. This kind of experimental thinking had been carried from projects like SOS2. The TouchDesigner component here was including an object detection module that I had trained using Google's Teachable Machine
